# Қазақша — казахский язык с нуля, A0 → A1

Открытый курс для русскоязычных начинающих: **50 модулей**, упражнения с проверкой и **150 готовых MP3**. Регистрация, сервер приложений и API-ключи для занятий не нужны.

**Сайт:** https://iskander87-dev.github.io/kazakh-a1-course/  
**Репозиторий:** https://github.com/iskander87-dev/kazakh-a1-course

## Содержание

Каноническая последовательность восстановлена из пользовательского курса StudyMe. Все 50 исходных уроков прочитаны; их текстовые блоки доступны в разделе «Чтение → Материалы исходного урока», упражнения перенесены в общую практику. Для каждого модуля добавлены цель, 8–12 слов, объяснение грамматики с примерами, текст с переводом, аудирование A/B/C, дополнительные задания, устная практика, повторение и критерий прохождения.

Блоки: 1–10 — первые слова и фонетика; 11–20 — семья, город, дом и календарь; 21–31 — грамматика и времена; 32–45 — бытовые ситуации; 46 — повторение; 47–50 — внутренняя проверка чтения, грамматики, диалогов и речи. Полный список с исходными ссылками находится в `data/plan.json`.

Исправления включают задний округлённый гласный Ұ; гармонию гласных; контрасты қ/к, ғ/г, ұ/ү, ы/і, о/ө, а/ә, н/ң; числа до 100; полную систему местоимений; множественное число; варианты падежных окончаний и вопросительных частиц; даты и месяцы; қол — рука, қолтаңба — подпись. Дополнительно исправлены төсек — кровать и фраза о супе. Формы после притяжательных окончаний объясняются отдельно. Ранние разговорные формулы можно запоминать целиком до системного разбора.

## Аудирование и проверка

* **A** — 8–12 слов урока.
* **B** — ключевые фразы.
* **C** — мини-диалог; вопрос проверяет понимание конкретной детали.

Порядок работы: слушать без текста → понять ситуацию и найти детали → открыть текст → повторить за диктором → произнести одну сторону диалога → снова слушать без текста. Скорость: 0.7× / 1.0× / 1.1×. Изменение скорости выполняет аудиоплеер браузера, отдельных тройных записей нет.

**Все записи синтетические**, голос `kk-KZ-AigulNeural` Microsoft, получены с помощью библиотеки `edge-tts`. Это MP3, а не зависящая от установленных голосов устройства браузерная озвучка. Носитель языка пока не проверял произношение; курс явно сообщает об этом возле аудиоплееров. [Официальный перечень казахских голосов](https://learn.microsoft.com/ru-ru/azure/ai-services/speech-service/language-support). Возможность повторного синтеза зависит от доступности поставщика.

Для зачёта модуля нужны ≥80% правильных ответов, завершённые дорожки A/B/C, правильный ответ на вопрос аудирования и самостоятельная отметка устной практики. Ошибки можно исправлять и перепроверять. Учёт достижений — внутренний ориентир, без официальной сертификации A1; автоматической оценки произношения нет. Для речи в модуле 50 есть рубрика самопроверки.

## Локальный запуск

Требуется Node.js 18 или новее. Сайт не использует npm-зависимости.

```sh
git clone https://github.com/iskander87-dev/kazakh-a1-course.git
cd kazakh-a1-course
npm start
```

Откройте http://127.0.0.1:4173 . В Windows при блокировке PowerShell используйте `npm.cmd start`. Не открывайте `index.html` через `file://`: данные загружаются через HTTP.

```sh
npm run build
npm run check
```

Сборка объединяет три части курса в `data/lessons.json`, затем копирует сайт в `dist/`. Проверка валидирует 50 модулей, словари, задания и индексы ответов, наличие 150 MP3, соответствие аудио текстам, длительности, контрольные суммы и условия прохождения.

## Структура исходников

* `index.html`, `styles.css`, `app.js`, `logic.js` — интерфейс и логика; ссылки на модули используют `#lesson/1`, поэтому работают на GitHub Pages без серверных маршрутов.
* `data/lessons-01-18.json`, `lessons-19-35.json`, `lessons-36-50.json` — редактируемые части курса; сюда перенесены исходные тексты и упражнения.
* `data/lessons.json` — общий файл для сайта.
* `audio/01-A.mp3` … `audio/50-C.mp3` — готовые дорожки.
* `data/audio-manifest.json` — текст синтеза, голос, длительность, SHA-256, отметки synthetic/nativeReviewed.
* `scripts/` — локальный сервер, сборка, проверка и повторное создание аудио.

Для изменения урока отредактируйте соответствующую часть JSON и выполните сборку. Если меняются words/phrases/dialogue, запустите генератор аудио: он сравнит тексты с манифестом и пересоздаст изменённые или отсутствующие MP3. Неизменённые записи сохраняются.

```sh
python -m pip install edge-tts==7.2.8 mutagen==1.48.1
python scripts/generate-audio.py
npm run check
```

## Бесплатная публикация через GitHub Pages

Сайт публикуется из `main`, корня `/`. В репозитории: **Settings → Pages → Deploy from a branch → main → /(root)**. Файл `.nojekyll` отключает обработку Jekyll. После изменения исходников выполните сборку и проверку, включите обновлённый `data/lessons.json` и MP3 в коммит и отправьте в `main`. GitHub Pages пересоберёт сайт. Папка `dist/` нужна только для других статических хостингов; на GitHub Pages она не требуется.

Все пути ресурсов относительные: сайт работает как в корне домена, так и в `/kazakh-a1-course/`. Ссылка на конкретный урок: https://iskander87-dev.github.io/kazakh-a1-course/#lesson/36 .

## Данные и доступность

Прогресс хранится в `localStorage` данного браузера. Он не синхронизируется между устройствами. При запрете сохранения сайт показывает сообщение и продолжает работу в текущей сессии. Логина, аналитики, рекламы и передачи ответов на сервер нет. Шрифт Manrope запрашивается из Google Fonts; при недоступности используется системный шрифт. MP3 и тексты обслуживает публичный GitHub Pages.

Интерфейс адаптирован для телефона и компьютера, формы имеют подписи, вкладки поддерживают клавиатуру, ошибки сопровождаются текстовыми пояснениями. Казахские буквы можно вставлять кнопками в разделе упражнений.
